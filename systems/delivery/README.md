# Delivery

Categoria para marketplaces e plataformas de entrega com APIs heterogêneas.

Provedores planejados:
- `ifood/`: simulador do iFood; rotas e schemas oficiais exigem validação documental.
- `99food/`: simulador da 99Food; rotas e schemas oficiais exigem validação documental.
- `delivery-a/`: contrato fictício existente no código legado em `src/providers/delivery-a`, a migrar.

Os provedores **não compartilham** um schema de negócio imposto pelo Mock Lab. O motor NØUS é responsável pela normalização posterior.
